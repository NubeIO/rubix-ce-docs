# Handover: Clean up & consolidate the Zone Controller Stack docs

## Goal
The `docs/Zone Controller Stack/` folder has accumulated **duplicate, stale, and
build-only files**: multiple PDFs (old + new), a self-contained PDF-build folder with its
own copy of every guide + image, a `pdf-toolkit`, and image directories that overlap.
Consolidate to **one clean source of truth per guide**, delete duplicates/old files, fix
path-casing landmines, and leave the doc site rendering exactly what it does today.

**Do NOT change guide content or structure** — that work is done and approved (commits
`fb2945d`, `2eb7da2`, `a981b71`). This is purely file/asset hygiene.

## Ground truth about how this repo works (verified — don't re-derive)
- **Sidebar is autogenerated from the filesystem**: `sidebars.js` →
  `{type: 'autogenerated', dirName: '.'}`. Every `.md` under `docs/` that isn't excluded
  becomes a live page. So moving/deleting a live `.md` changes the sidebar.
- **`docusaurus.config.js` already EXCLUDES two folders from the docs build**
  (lines 46–49):
  - `**/Zone Controller Stack/pdf-toolkit/**`
  - `**/Zoneconnex-Guides-v1.4-build/**`
  So those are **build/source assets, not live pages** — even though they physically live
  inside `docs/`. That's the core mess to resolve.
- Image sizing is CSS keyed on exact alt text `img[alt="maxNNNpx"]` in `src/css/custom.css`
  (buckets `max100..max900`; **no `max1000`**; `max50`=10px bug). Don't rename images in a
  way that breaks the `.md` references.
- Verify any change with `npm run build` (must stay green) + `npm start` (localhost:3000,
  baseUrl `/rubix-ce-docs/`). Broken image refs surface as build warnings /
  broken-image icons.

## Known landmines to FIX during cleanup (case-sensitive Linux deploy)
1. **Path-case inconsistency inside `Zoneconnex Quick Start Guide.md`**: it references
   both `ZoneConnex/img/…` (8×, capital C) and `Zoneconnex/img/…` (15×, lowercase). The
   folder on disk is `ZoneConnex/` (capital C). On macOS both resolve; on Linux the
   lowercase ones 404. **Normalise all refs to the real on-disk case.** (Decide the
   canonical folder name — recommend keeping disk `ZoneConnex/` and fixing the `.md`, or
   rename the folder + all refs to lowercase — pick one and be consistent.)
2. **`Zoneconnex INSTALL & USER MANUAL.md`** references `ZoneConnex-DinMounting-V2.png`
   (capital V) and `Wi-fi-connected.png`; disk has `…-v2.png` (lowercase) and
   `Wi-Fi-Connected.png`. **Fix to match disk casing.** (Surfaced as build casing
   warnings.)
3. After any image move/delete, re-run the reference check (script below) — zero misses
   required.

## Verification (run after every batch of deletions)
1. Reference-integrity check (no missing images across the 4 live guides):
   ```bash
   cd "docs/Zone Controller Stack"
   python3 - <<'PY'
   import re, urllib.parse, os, glob
   mds = ["Zoneconnex Quick Start Guide.md","Zoneconnex User Start Guide.md",
          "Zoneconnex INSTALL & USER MANUAL.md","MIA Mobile App/MIA App User Manual.md"]
   miss=0
   for md in mds:
       t=open(md).read()
       refs=set(m.split()[0] for m in re.findall(r'!\[[^\]]*\]\(([^)]+)\)', t))
       refs|=set(re.findall(r'require\("\./([^"]+)"\)', t))
       for p in refs:
           if p.startswith("http"): continue
           fp=urllib.parse.unquote(p)
           if not os.path.isfile(fp): miss+=1; print("MISSING", md, "->", fp)
   print("MISSES:", miss)
   PY
   ```
2. `npm run build` — green, and grep the log for "differ in casing" → must be **zero**.
3. `npm start`, open both guides + manual + MIA at `http://localhost:3000/rubix-ce-docs/…`
   and eyeball: no broken images, layout intact.
4. `git status` sanity — only intended deletions/moves staged.
